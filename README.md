# oPROsita - Plataforma para Academias de Oposiciones

Este repositorio contiene el código completo de **oPROsita**, una plataforma web orientada a academias de oposiciones, desarrollada como Trabajo de Fin de Grado de Ingeniería Informática en Tecnologías de la Información.

## 🚀 Lanzamiento rápido

Para ejecutar la aplicación completa en modo producción:

1. Clona este repositorio.
2. Lanza el script `start-prod.bat` desde la raíz del proyecto.
3. Abre tu navegador y accede a `http://localhost:4200`
4. Inicia sesión con uno de los usuarios de prueba indicados a continuación.

## 📦 Tecnologías utilizadas

- Frontend: Angular 18
- Backend: Spring Boot
- Seguridad: Keycloak (OIDC)
- Chat: Sendbird
- Orquestación: Docker & Docker Compose
- Contrato API: OpenAPI (API First)
